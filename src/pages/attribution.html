Where Workler came from

Workler is a fork of Jobber, an MIT-licensed job-search project created by santifer. The fork is maintained separately, under a different name, by a different maintainer. Upstream’s name, logo and other marks are not used here. The MIT licence covers the code; it does not transfer the marks to this project.

The lineage

Workler is based on Jobber, created by santifer and released under the MIT licence.

This project is a fork. It is maintained separately, developed independently, and named differently on purpose. Work done here is not upstream’s work, and problems here are not upstream’s problems — bug reports for Workler belong in Workler’s repository.

Upstream is a public repository under the MIT licence. Receipt → upstream

What the licence covers, and what it does not

The MIT licence covers code. It does not cover names or logos.

So: Workler uses upstream’s code under that licence, and does not use upstream’s name, wordmark, logo or any other brand asset. Upstream’s trademark policy permits describing a derived project as “based on Jobber”, and that is the only form used here. Workler has never been called Jobber and is not a renamed version of it.

The MIT licence text travels with the code and is in the repository. Receipt → the licence

Naming

“Jobber” is also the trademark of an unrelated field-service software company. Workler is not connected to that company either.
